  <section id="chapter1">
    <h2 class="chapter">第一章｜那年，我在人群中看見她</h2>
    <p>當時我在學校的街舞社，算是在學校小有名氣。高一的時候，因為一些特殊的原因，我有比較多的自由，不用把所有心思都放在讀書上，所以我幾乎把重心全部放在跳舞。</p>
    <p>那時候的我，很少參與班上的社交，也不太會主動認識其他同學。對我來說，跳舞才是最重要的事情。</p>
    <p>到了高二，我如願以償地在社團的 Battle 中脫穎而出，從大約一百人的社團裡，拿下了社長的位置。</p>
    <p>隨著名氣增加，身邊也開始出現一些傾慕者，但當時的我對她們都沒有興趣，所以全都婉拒了。</p>
    <p>直到高二的某一天。</p>
    <p>平常我都是在司令台上練舞，那天卻因為全校集合在操場，我難得跟班上的男生窩在一起。</p>
    <p>他們忙著看女生，班上甚至有個自稱「妹子雷達器」的人，只要是長得漂亮的女生，他幾乎都知道對方是誰、叫什麼名字，甚至連 Facebook 都找得到。</p>
    <p>平常我也會陪他們一起看、一起聊天，只是大多數時候，他們聊得開心，我則沒什麼感覺。</p>
    <p>但那一天，我在人群中看見了一個女生。</p>
    <p>我喜歡上她了。</p>
    <p>於是，我問了身邊的人：「那是誰？」</p>
    <p>後來，我加了她的 Facebook，開始認識她、追求她。</p>
    <p>最後，我如願以償地追到了她。</p>
    <p>我們在一起了，大約兩年的時間。</p>
  </section>

  <section id="chapter2">
    <h2 class="chapter">第二章｜第一段遺憾</h2>
    <p>到了高三畢業前，我面臨了一個選擇。</p>
    <p>我有一所很想念的大學，而她比我小一歲。假如我去了那所學校，我們之間可能就會出現距離的問題。</p>
    <p>當時，學務處和許多老師都很積極地幫我引薦、推薦，希望我能把握機會升學。</p>
    <p>最後，我做出了決定。</p>
    <p>我把這件事告訴她，而她也很支持我的選擇。</p>
    <p>那段時間，我忙著準備比賽，也忙著整理升學需要的資料，所以跟她聯絡的時間少了一些。</p>
    <p>但那時候的我，並不覺得這會成為什麼問題。</p>
    <p>畢竟，我一直認定她就是那個我未來一定會娶回家、想要一起走到最後的人。</p>
    <p>直到我真正進入那所大學，大約三個月後，我開始察覺到不對勁。</p>
    <p>她變了。</p>
    <p>她開始冷落我，對我的態度也越來越冷淡。我漸漸感覺到，自己好像不再是她那麼重視的人。</p>
    <p>我一直認為，感情裡有問題就應該攤開來說，而不是讓兩個人一直猜。</p>
    <p>所以，我試著跟她溝通。</p>
    <p>後來，我們吵了架。</p>
    <p>因為自己的不安全感，加上不想失去她，我最後選擇轉學，轉到離她比較近的學校。</p>
    <p>剛開始，情況似乎好轉了一陣子。</p>
    <p>但沒過多久，她又變回了原本冷漠的樣子。</p>
    <p>我不斷詢問她的好朋友、她的閨蜜，希望能知道究竟發生了什麼事。</p>
    <p>但她們始終守口如瓶，我什麼也問不出來。</p>
    <p>最後，她提出了分手。</p>
    <p>而她給我的分手理由，卻跟她之前所說的並不一樣。</p>
    <p>分手一個月後，我從還留在學校社團的學弟口中，得知了一件事。</p>
    <p>原來，在我離開學校後不久，她就已經跟別人在一起了。</p>
    <p>學弟告訴我，那段時間，他們經常在學校裡黏在一起。</p>
    <p>知道這件事後，我整個人都陷入了低潮。</p>
  </section>

  <section id="chapter3">
    <h2 class="chapter">第三章｜我等了她三年</h2>
    <p>分手後，我開始自暴自棄。</p>
    <p>那段時間，不管是誰想追求我，或是想進一步認識我，我一概拒絕。</p>
    <p>因為我做了一個決定。</p>
    <p>無論最後的結果是什麼，我都接受。</p>
    <p>我想等她。</p>
    <p>至於要等多久，我不知道。</p>
    <p>但我覺得，我等得起。</p>
    <p>於是，我就這樣等了三年。</p>
    <p>這三年裡，我沒有再接受任何人的感情。</p>
    <p>直到某一天，我的大學室友跟我說，他在迎新活動中認識了一個女生。</p>
    <p>他說，那個女生在迎新晚會上跳舞跳得非常出眾。</p>
    <p>我們就這樣閒聊著。</p>
    <p>聊到後來，他突然提到，那個女生跟我讀同一所高中，是觀光科的，比我小一歲，應該算是我的學妹。</p>
    <p>而且，她的姓氏很特別，姓溫。</p>
    <p>聽到這裡，我開始追問。</p>
    <p>最後才發現，他口中的女生，竟然就是我的前女友。</p>
    <p>我直接向室友坦白了我跟她之間的過去。</p>
    <p>因為他知道我們的故事，所以他最後勸我，不要再跟這個女生有任何交集了。</p>
    <p>他希望我能真正放下這段感情。</p>
    <p>但當時的我，並沒有真的放下。</p>
  </section>

  <section id="chapter4">
    <h2 class="chapter">第四章｜久別重逢</h2>
    <p>大約又過了三個月。</p>
    <p>有一天，我們翹課去咖啡廳吃飯。</p>
    <p>點完餐後，我們坐著等餐點。</p>
    <p>突然，一個熟悉的聲音傳進了我的耳裡。</p>
    <p>我抬起頭。</p>
    <p>沒錯，是她。</p>
    <p>那一刻，我們再次相遇了。</p>
    <p>後來回到家，她主動傳訊息給我，我們也重新有了聯繫。</p>
    <p>當時，我和室友們在外面租了一棟透天厝，而她也在學校附近租了房子。</p>
    <p>後來，在某個契機下，她邀請我去了她家。</p>
    <p>不知道是不是因為曾經在一起過，也不知道是不是因為我始終沒有真正放下她。</p>
    <p>當我再次走進她的生活時，那種熟悉的感覺又回來了。</p>
    <p>那段時間，我們就像以前還在一起的時候。</p>
    <p>有時候我住在她那裡，有時候她來我這裡。</p>
    <p>早上醒來，看見她就在自己身旁，那種感覺真實得讓我以為，我們真的重新在一起了。</p>
    <p>我們就這樣持續了大約兩個月。</p>
    <p>那兩個月裡，我幾乎又找回了曾經失去的幸福。</p>
    <p>但後來，一切又開始變了。</p>
    <p>她漸漸不再讓我去她家。</p>
    <p>一開始，我以為她只是需要一點距離，需要自己的空間，所以我沒有多想。</p>
    <p>然而，那種熟悉的冷漠感又慢慢回來了。</p>
    <p>從前，我們幾乎每天都能見面。</p>
    <p>後來，變成只有她主動叫我過去，我才能去找她。</p>
    <p>見面的頻率，也從每天一次，變成了一個星期大約兩次。</p>
    <p>那時候，只要我去她家，我都會幫她洗衣服、掃地、拖地。</p>
    <p>家裡大大小小的事情，幾乎都是我在做。</p>
    <p>直到有一天，我再次去她家。</p>
    <p>我發現，家裡比以前凌亂了許多。</p>
    <p>即使如此，我還是像往常一樣，開始收拾、打掃。</p>
    <p>我沒有想太多。</p>
    <p>因為一直以來，我對待每一段感情都有一個原則。</p>
    <p>我不查另一半的手機。</p>
    <p>我認為，如果一段感情需要靠翻手機、查訊息來維持安全感，那麼兩個人之間的信任，恐怕早就出了問題。</p>
    <p>與其每天疑神疑鬼，不如坦誠相待。</p>
    <p>我不希望自己的感情，最後變成一場互相猜疑的遊戲。</p>
    <p>但那一天，發生了一件事。</p>
    <p>當她去洗澡時，她的手機突然連續收到好幾則訊息。</p>
    <p>我很掙扎。</p>
    <p>一方面，我的好奇心讓我很想知道發生了什麼事；另一方面，我又不想違背自己一直以來的原則。</p>
    <p>最後，我還是走近看了一眼。</p>
    <p>我沒有解鎖手機，也沒有翻閱任何訊息。</p>
    <p>但我看見了傳訊息的人，以及對方傳來的稱呼。</p>
    <div class="quote">「寶貝。」<br>後面還跟著三個愛心。</div>
    <p>那一刻，我大概已經知道是怎麼回事了。</p>
    <p>等她洗完澡出來後，我沒有拐彎抹角，而是直接開口問她。</p>
    <p>結果，她非常生氣。</p>
    <p>我們爆發了激烈的爭吵，最後，她直接把我趕了出去。</p>
    <p>從那天開始，我們就再也沒有聯絡。</p>
    <p>我傳給她的訊息，她沒有已讀。</p>
    <p>我也再看不到她的 Instagram。</p>
    <p>我又花了很長一段時間，才慢慢從這段關係帶來的難過中走出來。</p>
    <p>我以為，這一次，我們是真的結束了。</p>
    <p>直到大約半年後。</p>
    <p>她又傳訊息給我。</p>
    <p>只有短短一句話。</p>
    <div class="ending">「<span>在嗎？我想妳了。</span>」</div>
  </section>
